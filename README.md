# Gallery (Fire Max 11)

Image viewer for Amazon Fire tablets (Fire OS 8 / Android 11+). Lists every folder on the tablet that has images, and shows a folder (with its subfolders) as a thumbnail grid or a full-screen slideshow. Opens images from other apps through **Open with**. Supports JPEG, PNG, WebP, GIF, BMP and HEIC (where the tablet can decode it), and plays animated GIF, WebP and APNG.

## Build

    export JAVA_HOME=/usr/lib/jvm/java-17-openjdk-amd64
    ./gradlew :app:assembleDebug        # APK: app/build/outputs/apk/debug/app-debug.apk
    ./gradlew :app:testDebugUnitTest    # JVM tests
    ./gradlew :app:connectedDebugAndroidTest   # needs an emulator or device on adb

Test fixtures are generated by `python3 -I tools/make_test_assets.py` (needs Pillow and `gif2webp`) and are committed.

## Install on the Fire tablet

There are two ways to get the app onto the tablet. Route A needs only the tablet. Route B uses a PC and a USB cable.

### Route A: download on the tablet (no PC needed)

1. On the Fire Max 11, open the **Silk Browser**.
2. Go to the latest release page: https://github.com/jjveleber/gallery/releases/latest
3. Under **Assets**, tap the file named `gallery-vX.Y.Z.apk` (for example `gallery-v0.1.0.apk`). If Silk warns that the file might be harmful, tap **Download anyway**.
4. When the download finishes, tap **Open** in the download bar. You can also open it later from the **Files** app, in the **Downloads** folder.
5. The first time, Fire OS blocks installs from Silk. Allow it, using either of these:
   - Tap **Settings** on the prompt that appears, turn on **Allow from this source**, then press Back.
   - Or go to **Settings > Security & Privacy > Apps from Unknown Sources**, tap **Silk Browser**, and turn on **Allow from this source**.
6. Tap **Install**, wait for it to finish, then tap **Open** (or **Done**).
7. From then on, find **Gallery** in the app grid on the home screen (swipe up or open the **Library** if it is not on the first page).

Optional: once installed, you can go back to **Apps from Unknown Sources** and turn Silk off again. The app stays installed.

### Route B: install from this WSL2 PC with adb

1. On the tablet: **Settings > Device Options > About Fire Tablet**, tap **Serial Number** 7 times. This unlocks Developer Options.
2. Go to **Settings > Device Options > Developer Options** and turn on **USB debugging** (ADB).
3. Connect the tablet to the Windows PC by USB and tap **Allow** on the debugging prompt on the tablet.
4. WSL cannot see USB devices directly, so use the Windows adb. From the repo folder in WSL:

       cp app/build/outputs/apk/debug/app-debug.apk /mnt/c/Users/jjvel/Downloads/gallery.apk
       /mnt/c/Users/jjvel/AppData/Local/Android/Sdk/platform-tools/adb.exe install -r 'C:\Users\jjvel\Downloads\gallery.apk'

5. When it prints `Success`, find **Gallery** in the app grid on the tablet.

## Using it

- **Photo access:** the first time you open Gallery it asks for access to your photos. Tap **Allow**; Android remembers it. If you tap **Don't allow**, Gallery works as before: tap **Pick folder** and choose a folder in the system picker each time. If you tap **Don't allow** twice, Android stops asking. To change your mind later, go to **Settings > Apps & Notifications > Manage All Applications > Gallery > Permissions** and allow storage (photos and media) access.
- **Folders:** with access allowed, Gallery starts with a list of every folder that has images, with how many images are in it (including its subfolders) and a cover picture. A folder that only holds subfolders with images, such as Pictures, is listed too. Tap a folder to see it and all its subfolders. Gallery reopens the last folder you opened from this list the next time you start it. Tap **Folder** in the grid top bar to get back to the list.
- **Browse other folder:** if a folder is missing from the list (for example it has a `.nomedia` file, or it is on storage the tablet does not index), tap **Browse other folder** at the top of the list and pick it in the system picker. Folders picked this way are not reopened on the next start, and picking one replaces the remembered folder, so the next start opens the folder list.
- **Grid:** pinch to change the thumbnail size, or use the **+** icon (Size) in the top bar. The **Sort** icon in the top bar offers name, date modified, folder path, file size and random (with **Reshuffle**), ascending or descending. Animated images show an **ANIM** badge unless **Animate thumbnails** is on in Settings (the gear icon). GIFs larger than about 1 megapixel always show a still with the **ANIM** badge in the grid, even with **Animate thumbnails** on; they animate full screen.
- **Full screen:** tap a thumbnail (it opens static, so you only swipe; **Play** in the grid or **Play** in the viewer controls starts the slideshow). Swipe, or tap the left or right edge, to move between images; it wraps around at the ends. Pinch or double-tap to zoom. Tap the middle to show the controls: **Play**/**Pause** auto advance, the interval (tap to change), and Settings.
- **Play** (the play icon in the grid top bar) starts a slideshow from the first image.
- **Duplicates:** opening a folder starts a background search for byte-identical copies (across every folder with photo access allowed). Images with a copy get a yellow **DUP** badge, and the **Duplicates (N)** button in the top bar shows only those, with each image's copies next to it. Full screen, the controls name the other copy.
- **Delete:** press and hold a thumbnail to select (then **Select extra copies** keeps one of each duplicate group), or use the trash icon in the full-screen controls. Images from the folder list go to the Android trash after the system asks you to confirm (erased after about 30 days); files in a folder picked with **Browse other folder** are deleted for good after Gallery asks you to confirm.
- **Open with:** works from the Fire **Files** app and from ES File Explorer. Long-press an image, choose **Open with**, then **Gallery**. With photo access allowed you can swipe through the other images in the same folder. If you deny it, or the app cannot work out or list the folder, a **Browse this folder** button (shown as a chip) appears: tap it and pick the folder once.

- **Crash report:** if Gallery crashes, the next launch shows the report in a dialog. Tap **Copy** to put it on the clipboard so you can send it to the developer, or **Dismiss** to delete it. Closing the dialog with Back or by tapping outside it keeps the report, so it shows again next launch; only **Dismiss** deletes it. After a crash the app opens at the folder list instead of the last folder, so a folder that crashed cannot crash it again; tap the folder in the list to open it. If the system kills Gallery for low memory, no report is saved.

For a full walkthrough with screenshots, see the [usage guide](docs/usage.md).

Your sort order and grid size (top bar), the options in the Settings sheet (animation switches, interval, transition) and the last folder you opened from the folder list are all saved between launches.

Known limitation: with **Animate thumbnails** on, animating many GIFs of up to 1 megapixel each in the grid can still use a lot of memory.

## Updating to a newer version

Download or copy the newer APK and install it over the top, the same way as the first install (Route A steps 2 to 6, or Route B step 4). Do not uninstall first. Your settings are kept. Both routes install the same build, so you can update over the top by either route.

## Uninstalling

Press and hold **Gallery** in the app grid and tap **Uninstall** (or go to **Settings > Apps & Notifications > Manage All Applications > Gallery > Uninstall**). This deletes your settings and the saved duplicate-search results. Your images are not touched.
